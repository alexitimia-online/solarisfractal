SOLARIS FRACTAL — COMING SOON
Paquete estático listo para Netlify

CONTENIDO
index.html               Página principal
css/styles.css           Estilos responsive
assets/                   Artes separados
  first-resonance.webp    Fondo principal
  solaris-wordmark.webp   Wordmark aprobado
  favicon.png             Icono del sitio
  og.png                  Arte al compartir el enlace
_headers                  Seguridad y caché para Netlify

PUBLICAR EN NETLIFY
1. Entra a https://app.netlify.com/drop
2. Arrastra este ZIP completo o la carpeta Solaris-Fractal-Coming-Soon.
3. Netlify publicará la página automáticamente.
4. En Domain management, conecta solarisfractal.com.

IMPORTANTE
No subas solamente index.html: las carpetas css y assets deben conservarse
en la misma estructura para que carguen el diseño y las imágenes.

El paquete es HTML/CSS puro. No necesita npm, React, compilación ni variables
de entorno.
